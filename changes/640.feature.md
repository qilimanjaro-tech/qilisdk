Added a circuit constructor to more easily create Grover-style circuits. Amplitude amplification is the quantum algorithm for making a circuit bitstring more likely, made of two parts, an oracle and a diffusion operator. This handy constructor does both for a circuit bitstring on certain qubits. Usage:

```python
from qilisdk.digital import Circuit, H
from qilisdk.backends import QiliSim
from qilisdk.functionals import DigitalPropagation
from qilisdk.readout import Readout
import numpy as np

n = 3

grover = Circuit(n)
grover.add([H(q) for q in range(n)])
grover += Circuit.amplitude_amplification("101", qubits=[0, 1, 2], nqubits=n, iterations=1)

sim = QiliSim()
functional = DigitalPropagation(grover)
readout = Readout().with_sampling(1000)
result = sim.execute(functional, readout)
print(result)
```
