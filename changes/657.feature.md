The `Model.random_knapsack()` now by default generates a knapsack problem with integer coefficients, i.e. `Model.random_knapsack(value_range=(1,10))` now generates with coefficients like 1,2,...,9,10, rather than real values. This form of knapsack is the same complexity class (i.e. it's still hard), it just converts to QUBO form better and is the more standard form when benchmarking QUBO stuff. The old behaviour can be re-enabled with  `Model.random_knapsack(value_range=(1,10), integer=False)`.
