A distinction has been made between Functionals and Algorithms: Functions (now just `DigitalPropagation` and AnalogEvolution) are the primitive classes upon which Algorithms (now `VariationalProgram` and `QuantumReservoir`) are built. Each algorithm is now in charge of handling it's own execution via an `_execute` method, rather than having it all in `Backend`. The API change is that now `VariationalProgram` and `QuantumReservoir` are imported from `qilidsk.functionals`:

```python
from qilisdk.algorithms import VariationalProgram, QuantumReservoir
from qilisdk.functionals import DigitalPropagation, AnalogEvolution
```
