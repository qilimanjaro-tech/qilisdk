A distinction has been made between Functionals and Algorithms: Functionals (now just `DigitalPropagation` and `AnalogEvolution`) are the primitive classes upon which Algorithms (now `VariationalProgram` and `QuantumReservoir`) are built. Each algorithm is now in charge of handling its own execution via an `_execute` method, rather than having it all in `Backend`. The API change is that `VariationalProgram` and `QuantumReservoir` are now imported from `qilisdk.algorithms`:

```python
from qilisdk.algorithms import VariationalProgram, QuantumReservoir
from qilisdk.functionals import DigitalPropagation, AnalogEvolution
```

Importing them from `qilisdk.functionals` still works for now, but raises a `DeprecationWarning`.

Backend subclasses that call `super()._execute_variational_program()` or `super()._execute_quantum_reservoir()` must be updated, as `Backend` no longer defines these methods. Defining them in a subclass still overrides the algorithm's own `_execute`.
