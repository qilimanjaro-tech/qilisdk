Added the ability to update the coefficient of a schedule without reconstructing the whole thing:

```python
from qilisdk.analog import Schedule, X, Z

sched = Schedule.linear(X(0), Z(0), total_time=10, dt=1)
sched.set_coefficient("driver", 0.5)
print(sched)

#     'problem': {0.0: t * (0.1), 10.0: t * (0.1)},
#   },
#   dt=1,
#   total_time=None,
#   interpolation=None
```
