`QTensor` now has an `entanglement_entropy(qubits, alpha=1)` method. It returns the entropy of the reduced density matrix of a subset of qubits. With the default `alpha=1` this is the von Neumann entropy, and other values of `alpha` give the Rényi entropy. It works on kets, bras and density matrices.

```python
from qilisdk.core.qtensor import QTensor

# Each half of a Bell pair is maximally entangled with the other
print(QTensor.ghz(2).entanglement_entropy([0]))  # log(2) ≈ 0.693

# Product states have no entanglement across any cut
print(QTensor.ket(0, 1, 1).entanglement_entropy([0, 2]))  # 0.0

# Rényi entropies of other orders are also supported
print(QTensor.ghz(4).entanglement_entropy([0, 1], alpha=2))  # log(2) ≈ 0.693
```
