The Expression class has been moved to C++. This means a lot better performance for working with Models and QUBOs. Some benchmarks:

| Model | Step | Before | After | Speedup |
|---|---|---|---|---|
| `Model.random_ising(300)` | build | 0.87 s | 0.17 s | 5x |
| | `to_qubo()` | 8.25 s | 0.22 s | 38x |
| | `to_hamiltonian()` | 1.67 s | 0.86 s | 2x |
| `Model.knapsack(...)` with 400 items | build | 0.43 s | 0.003 s | 140x |
| | `to_qubo()` | 4.18 s | 0.16 s | 26x |
| | `to_hamiltonian()` | 7.89 s | 1.57 s | 5x |
| `Model.random_travelling_salesman(14)` | build | 25.6 s | 0.04 s | 670x |
| | `to_qubo()` | 0.16 s | 0.01 s | 16x |
| | `to_hamiltonian()` | 0.96 s | 0.10 s | 9x |

The interface remains the exact same, so it won't change your workflow, it will just speed bits up.
