Added `Circuit.adjoint()` to get the adjoint of a whole circuit. This corresponds to the gates in reverse order, with each gate replaced by its adjoint. Many gates are self-adjoint, which are therefore not affected. For example:

```python
from qilisdk.digital import Circuit, H, X, S

circuit = Circuit(2)
circuit.add(H(0))
circuit.add(X(0))
circuit.add(S(0))
print(circuit)
# Circuit(nqubits=2, gates=[H(0), X(0), S(0)])
print(circuit.adjoint())
# Circuit(nqubits=2, gates=[S†(0), X(0), H(0)])
```
