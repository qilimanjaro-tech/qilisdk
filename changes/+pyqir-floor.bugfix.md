Corrected the lower bounds of two extras. `qir` now needs `pyqir>=0.12.0`, since `to_qir` and `from_qir` use `pyqir.ptr_id`, which does not exist before that release, and `scip` now needs `pyscipopt>=5.2.1`, the first release with wheels for every Python version QiliSDK supports. Missing-extra install hints also name the right extra now, `pip install qilisdk[qir]` rather than the non-existent `qilisdk[pyqir]`.
