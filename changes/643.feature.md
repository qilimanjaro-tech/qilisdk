Added `Circuit.period_finding`, which builds the period finding circuit at the heart of Shor's algorithm. For example, factoring 21 with QiliSim:

```python
import math
from fractions import Fraction

from qilisdk.backends import QiliSim
from qilisdk.digital import Circuit
from qilisdk.functionals import DigitalPropagation
from qilisdk.readout import Readout

# We want to factor 21
a, N = 2, 21

# Construct and run the quantum part
circuit = Circuit.period_finding(a, N)
nprecision = circuit.nqubits - (N - 1).bit_length()
samples = QiliSim().execute(DigitalPropagation(circuit), Readout().with_sampling(nshots=100)).get_samples()

# Each sample gives m / 2^nprecision ~ s / r, so the period r is one of the continued fraction denominators
denominators = {Fraction(int(bits[:nprecision], 2), 2**nprecision).limit_denominator(N).denominator for bits in samples}
r = min(d for d in denominators if pow(a, d, N) == 1)  # 6

# Thus via the gcd we get our factors, in this case 7 and 3
print(math.gcd(a ** (r // 2) - 1, N), math.gcd(a ** (r // 2) + 1, N))
```
