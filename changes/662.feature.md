Added TopologyPreset with presets for common hardware layouts (line, ring, grid, all_to_all, heavy_hex, plus from_coupling_map), which can be passed anywhere a coupling map is accepted.

```python
from qilisdk.digital import CNOT, Circuit, CircuitTranspiler, H, TopologyPreset

# 2x3 grid
topology = TopologyPreset.grid(rows=2, cols=3)

circuit = Circuit(4)
circuit.add(H(0))
for target in range(1, 4):
    circuit.add(CNOT(0, target))

result = CircuitTranspiler.default(topology=topology).transpile(circuit)
print(result.layout)
```
