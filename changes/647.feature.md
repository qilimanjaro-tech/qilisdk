Added barrier gates. These can be used to separate sections of the circuit so they are easier to see visually. For now they are ignored in transpilation and simulation.

```python
from qilisdk.digital import Barrier, Circuit, H

circuit = Circuit(3)
circuit.add(H(0))
circuit.add(Barrier())
circuit.add(H(1))
circuit.add(H(2))
circuit.draw()
```
