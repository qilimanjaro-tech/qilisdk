`QTensor` now has a `fermionic_antiflatness(k=1)` method. It computes the fermionic antiflatness (FAF) of a pure state, a measure of how far the state is from being fermionic Gaussian ("fermionic magic"), from [Sierant, Stornati and Turkeshi, arXiv:2506.00116](https://arxiv.org/abs/2506.00116).

```python
import numpy as np
from qilisdk.core.qtensor import QTensor

# Computational basis states are fermionic Gaussian, so their antiflatness vanishes
print(QTensor.zero(4).fermionic_antiflatness())  # 0.0

# The 3-qubit GHZ state mixes fermionic parity sectors, giving the maximal value N = 3
print(QTensor.ghz(3).fermionic_antiflatness())  # 3.0

# Higher orders k are supported, and Haar-random states sit close to the maximum N
print(QTensor.random(10, seed=42).fermionic_antiflatness(k=2))  # ~9.993
```
