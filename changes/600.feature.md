QiliSim now uses a single thread for small (i.e. 12 for digital, 9 for analog) jobs, for improved performance.

| Run | New default | Old default (all cores) |
|---|---|---|
| digital, 8 qubits | 0.58 ms | 0.94 ms |
| digital, 16 qubits | 2.79 ms | 2.88 ms |
| analog, 4 qubits | 0.79 ms | 1.23 ms |
| analog, 12 qubits | 3.17 ms | 3.25 ms |
