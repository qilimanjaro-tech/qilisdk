Added some new circuit metrics to `Circuit`: `Circuit.ngates`, `Circuit.gate_counts` and `Circuit.depth`. Usage:

```python
from qilisdk.digital import Circuit, H, CNOT

c = Circuit(3)
c.add(H(0))
c.add(H(1))
c.add(CNOT(0, 1))
c.add(CNOT(1, 2))

print(c.ngates)  # 4
print(c.gate_counts)  # {'H': 2, 'CNOT': 2}
print(c.depth)  # 3
```
