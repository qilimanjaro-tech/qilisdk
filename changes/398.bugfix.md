The way CudaBackend internally handles digital noise has been refactored to be more consistent with how QiliSim handles it, specifically it now has a function which returns all noise types acting on a specific qubit/gate, which are then turned into Kraus operators, expanded as needed, and given to the simulation. This still keeps the efficient CUDA bitflip channels etc. and nothing about the public-facing API has changed. This now allows for things like noise acting on multi-qubit gates, which were previously just ignored.
