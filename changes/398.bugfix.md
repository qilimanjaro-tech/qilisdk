CudaBackend now handles noise on multi-qubit gates correctly: previously if you had noise on qubit 1 and then did a swap or a CNOT involving qubit 1, the noise was dropped entirely. It is now applied to that qubit alone, whether it is a target or a control.

Global and per-gate noise is now applied independently to each qubit a gate acts on, instead of as one correlated operator across the qubits.

A global multi-qubit Kraus channel is now applied to any gate acting on that many qubits, rather than only to a gate spanning the whole register. Channels that do not fit the gate are skipped with a warning.
