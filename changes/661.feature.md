Adds a new method for checking whether two circuits are equivalent up to some global phase: `Circuit.is_equivalent_to(Circuit)`.

```python
from qilisdk.digital import RZ, U1, Circuit

a = Circuit(1)
a.add(RZ(0, phi=0.5))
b = Circuit(1)
b.add(U1(0, phi=0.5))
a.is_equivalent_to(b)  # True: RZ and U1 differ only by a global phase
```
