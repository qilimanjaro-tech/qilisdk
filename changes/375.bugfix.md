A bug was fixed in which the topology-aware transpiler applied the initial layout twice, specifically that `SabreLayoutPass` retargeted the circuit onto physical qubits and also recorded the mapping in the transpilation context, so `SabreSwapPass` applied the same mapping again and inserted SWAPs that were not needed. The reported `result.layout` was also keyed on physical labels rather than logical qubits, so reading it could return the wrong qubit or raise an `IndexError`.
