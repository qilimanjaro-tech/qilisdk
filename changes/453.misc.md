Lowered the runtime dependency floors to the oldest versions QiliSDK actually works with, so it constrains the environments it is installed into as little as possible: `dill>=0.3.9`, `ruamel-yaml>=0.18.7`, `pydantic>=2.12.0`, `matplotlib>=3.10.5`, `rustworkx>=0.16.0` and `psutil>=6.1.0`. `numpy`, `scipy` and `loguru` were already at their oldest workable versions. `pydantic-settings` went the other way, to `>=2.14.2`, so an install cannot resolve below the version that fixes its advisory. `setuptools` was dropped altogether, nothing in QiliSDK imports it and the build backend does not need it either.
