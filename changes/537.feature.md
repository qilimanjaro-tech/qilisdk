The performance of the variational annealing method has been improved, via better hashing, not using OpenMP for small workloads, using a smaller formulation of the problem if the number of samples is less than the number of parameters, and a few other small tweaks. It now doesn't have such a big overhead for tiny qubit counts.

| Qubits | Before  | After   | Speedup |
|-------:|--------:|--------:|--------:|
| 1      | 102 ms  | 3.7 ms  | 28×     |
| 2      | 103 ms  | 6.7 ms  | 15×     |
| 4      | 103 ms  | 13.6 ms | 7.6×    |
| 32     | 2.37 s  | 0.31 s  | 7.7×    |
| 48     | 13.6 s  | 0.66 s  | 20×     |
