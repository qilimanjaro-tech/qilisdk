A new circuit simulation method has been added to QiliSim: a belief propagation (BP) tensor network simulator, `DigitalMethod.bp()`. Instead of a chain like MPS, the state is a tensor network shaped like the circuit's own interaction graph, with one tensor per qubit and one bond per pair of qubits each two-qubit gate acts on. This is exact on tree-shaped circuits and approximate on graphs with loops. Expectation values and exact state tomography are supported, but sampling is not.

Since there are no swaps and no long chain to route entanglement through, it can be much faster than MPS for circuits whose connectivity is not a line. For example, for a few QAOA-like layers on a 63 qubit binary tree, BP takes around 0.06 seconds and gives the exact result. MPS takes around 17 seconds and, even with a bond dimension of 64, truncates heavily and gets the wrong answer:

```python
from qilisdk.analog import Z
from qilisdk.backends import DigitalMethod, ExecutionConfig, QiliSim
from qilisdk.digital import CNOT, RX, RZ, Circuit, H
from qilisdk.functionals import DigitalPropagation
from qilisdk.readout import Readout
import time

# A binary tree of qubits
nqubits = 63
edges = [((i - 1) // 2, i) for i in range(1, nqubits)]

# A few layers of ZZ rotations along the edges and X rotations on every qubit
circuit = Circuit(nqubits)
for q in range(nqubits):
    circuit.add(H(q))
for _ in range(3):
    for a, b in edges:
        circuit.add(CNOT(a, b))
        circuit.add(RZ(b, phi=0.6))
        circuit.add(CNOT(a, b))
    for q in range(nqubits):
        circuit.add(RX(q, theta=0.5))

# Measure the energy of the cut along the edges
cost = sum(Z(a) * Z(b) for a, b in edges)
readout = Readout().with_expectation([cost])

for name, method in [("bp", DigitalMethod.bp()), ("mps", DigitalMethod.mps())]:
    backend = QiliSim(digital_simulation_method=method, execution_config=ExecutionConfig(seed=42, num_threads=8))
    t0 = time.time()
    val = backend.execute(DigitalPropagation(circuit), readout).get_expectation_values()[0]
    print(f"{name}: {time.time() - t0:.2f} seconds, val: {val:.6f}")
```
