`CudaqBackend` and `QutipBackend` now check the version of the framework you installed, not just that it is there. CUDA-Q below 0.14.0, QuTiP below 5.2.2 or qutip-qip below 0.4.0 raise `OptionalDependencyError` on first use, naming the version that was found and the one that is needed. These are the versions the test suite runs against.
