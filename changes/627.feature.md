`QTensor` now has a `gap_ratio()` method. It returns the mean level spacing ratio ⟨r⟩ of a Hermitian operator, such as a Hamiltonian, averaged over its whole spectrum. Each ratio is r = min(sₙ, sₙ₋₁) / max(sₙ, sₙ₋₁), where sₙ are the gaps between neighbouring eigenvalues. 

```python
import numpy as np

from qilisdk.core.qtensor import QTensor

# Spacings of 1, 2 and 4 give ratios of 1/2
print(QTensor(np.diag([0.0, 1.0, 3.0, 7.0])).gap_ratio())  # 0.5

# A random complex Hermitian matrix follows GUE statistics
rng = np.random.default_rng(4)
a = rng.standard_normal((1024, 1024)) + 1j * rng.standard_normal((1024, 1024))
print(QTensor(a + a.conj().T).gap_ratio())  # ≈ 0.600

# Uncorrelated levels follow Poisson statistics
print(QTensor(np.diag(rng.uniform(size=1024))).gap_ratio())  # ≈ 0.386
```
