A bug was fixed in which `Schedule.draw()` labelled its plot "Schedule Eigenvalues", because it fell back to the shared renderer default title instead of setting its own. `Schedule.draw()` now titles the plot "Schedule Coefficients" (which is what it actually plots) and `Schedule.draw_eigenvalues()` titles it "Schedule Eigenvalues"; passing an explicit `ScheduleStyle(title=...)` still overrides both.
