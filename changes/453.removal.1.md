**Breaking change.** QiliSDK no longer installs CUDA-Q or QuTiP. `CudaqBackend` and `QutipBackend` now work against whatever version of their framework you have installed yourself: `pip install cuda-quantum-cu12` (or `cuda-quantum-cu13`) for `CudaqBackend`, `pip install qutip qutip-qip` for `QutipBackend`. The `qutip` extra is gone, and the `cuda`, `cuda12` and `cuda13` extras now only install the CUDA math libraries that give QiliSim GPU support. Everything else is unchanged: the backends are still imported lazily, and asking for one whose framework is missing still raises `OptionalDependencyError` with an install hint.
