Added support for Python 3.14. Wheels are published for it, and the test suite, the type checks and the platform builds all run against it. `CudaqBackend` is the one exception: CUDA-Q publishes no Python 3.14 wheels, so it stays unavailable there and asking for it raises the usual `OptionalDependencyError`. Supporting 3.14 raised a few lower bounds to the first release with wheels for it: `numpy>=2.3.2`, `scipy>=1.16.1` and, for the `scip` extra, `pyscipopt>=5.7.0`.
