Corrected the lower bound of the `qir` extra. It now needs `pyqir>=0.12.0`, since `to_qir` and `from_qir` use `pyqir.ptr_id`, which does not exist before that release. Missing-extra install hints also name the right extra now, `pip install qilisdk[qir]` rather than the non-existent `qilisdk[pyqir]`.
