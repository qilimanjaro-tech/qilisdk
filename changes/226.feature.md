Introduced a real expression-tree AST rooted at the new `qilisdk.core.Expression` base class, replacing the previous flattened-polynomial model. Building expressions is unchanged: `2 * BinaryVariable("b") + 1` and every other arithmetic spelling still works exactly as before, the resulting object is just an `Expression` instead of a `Term`. Symbolic values (gate angles, Hamiltonian coefficients, schedule coefficients, model objectives/constraints) are now uniformly typed `Expression`, built from `Add`/`Mul`/`Pow`/`Constant` and the unary `Function` nodes `Sin`/`Cos`/`Exp`/`Log`/`Tan`/`Sqrt`/`Abs`. The new tree adds symbolic differentiation (`Expression.derivative`), distribution (`Expression.expand`), substitution (`Expression.substitute`), operand listing (`Expression.to_list`), arbitrary unary functions, and non-integer/symbolic powers, while preserving order-independent structural equality (`x + y == y + x`). `Variable` now defaults to `Domain.INTEGER`, so the domain only has to be passed when you want a different one. It also fixes a wrong-answer bug in the old model, where a product of two identical function terms collapsed into a sum: `Sin(x) * Sin(x)` evaluated as `2 * sin(x)` and is now `sin(x) ** 2`.
