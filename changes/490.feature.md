Big circuits are now rendered better, both in notebooks and in normal Python. Circuits are wrapped and have better performance when scrolling, since now non-visible gate aren't rendered. The wrapping can be controlled with the new `fold` and `row_separation` attributes.

```python
from qilisdk.digital import Circuit, X
from qilisdk.utils.visualization import CircuitStyle
circuit = Circuit(3)
for _ in range(30):
    circuit.add(X(0))
circuit.draw(style=CircuitStyle(fold=10, row_separation=1.5))
```
