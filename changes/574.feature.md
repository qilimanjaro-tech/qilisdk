Models with real-valued constraints are now converted to QUBO better. Previously, something like `2.5 * a + 2.5 * b <= 4.9`, where `a` and `b` are binary values, would get converted into `2.5 * a + 2.5 * b + s = 4.9` where `s` is a positive integer slack variable. Since this slack variable can only take the values 0,1,2 etc. it meant that setting only one of `a` or `b` to be 1 and the other to 0 (which is only valid solution) would result in a higher slack than needed, leading to the valid solutions not being the optimum in terms of QUBO objective. By first converting constraints with real number to integers via a GCD, we remove this issue and give better performance for the QUBO form of such models.
